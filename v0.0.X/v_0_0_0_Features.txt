## 🎮 How to Use

**To run the game:**
1. Save the artifact as `serpents_code.py`
2. Run: `python serpents_code.py`
3. Follow the adventure!

**Your progress** will be saved in `player_data.json` in the same directory.

## 🔧 Easy to Extend

To add more quests, simply:
1. Create a new function following the pattern (e.g., `quest4_numbers_nature`)
2. Add it to `self.quest_functions` dictionary in `GameEngine.__init__()`
3. The quest will automatically appear in the game!
