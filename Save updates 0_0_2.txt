## Key Features:

### 1. **Cross-Platform Save Locations**
- **Windows**: `%APPDATA%/SerpentsCode/saves/`
- **macOS**: `~/Library/Application Support/SerpentsCode/saves/`
- **Linux**: `~/.local/share/SerpentsCode/saves/`
- **Fallback**: Current directory if home folder isn't accessible

### 2. **Multiple Save Slots**
- 3 save slots for different playthroughs
- Each slot shows player name, level, XP, and last saved time
- Autosave slot (separate from manual saves)

### 3. **Backup System**
- Automatic backup before overwriting saves
- Can recover from corrupted saves
- Atomic file operations (writes to temp file first)

### 4. **Import/Export**
- Export saves to share or backup externally
- Import saves from other computers
- Portable save files

### 5. **Better Error Handling**
- Clear error messages
- Permission testing before saving
- Multiple fallback options
