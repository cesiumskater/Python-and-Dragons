## Example Use Cases

### Blue Team / SOC Analyst
```python
# Parse logs with regex
import re
log_data = open('/var/log/auth.log').read()
failed_logins = re.findall(r'Failed password.*from (\\d+\\.\\d+\\.\\d+\\.\\d+)', log_data)

# Automated alerting
import smtplib
if len(failed_logins) > 10:
    send_alert_email('High failed login count!')
```

### Red Team / Penetration Tester
```python
# Port scanning
import socket
for port in range(1, 1024):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    result = sock.connect_ex(('target.com', port))
    if result == 0:
        print(f'Port {port}: OPEN')

# Web enumeration
import requests
response = requests.get('https://target.com/admin')
if response.status_code == 200:
    print('Admin panel found!')
```
