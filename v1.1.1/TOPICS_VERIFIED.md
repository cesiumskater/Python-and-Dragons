## Architecture Highlights

### Separation of Concerns
- **TopicRegistry** - Central topic database
- **TableOfContents** - Navigation system
- **LessonFactory** - Creates lessons on demand
- **GameProgress** - Tracks user progress
- **Game** - Main controller

### Dual-Mode Design
```
Story Mode          Reference Mode
    ↓                     ↓
Linear Acts    ←→  Random Access TOC
    ↓                     ↓
Unlock Acts     Independent of Story
    ↓                     ↓
current_act     visited_topics list
```

This design allows:
- Reading ahead in Reference Mode
- Without skipping story Acts
- Like a textbook with optional narrative
