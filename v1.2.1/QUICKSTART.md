# Quick Start Guide - The Verdant Code v1.2.1

## Get Started in 5 Minutes

### Requirements
- Python 3.8 or higher
- Terminal/Command Prompt

### Run the Game

**Windows:**
```cmd
cd "C:\Users\YourName\Documents"
python the_verdant_code_1.2.1.py
```

**macOS/Linux:**
```bash
cd ~/Documents
python3 the_verdant_code_1.2.1.py
```

### First Time Setup

1. **Pre-Flight Check**
   - Automatically verifies your Python installation
   - Checks Git (optional, needed for Act VIII)
   - Confirms file permissions

2. **Skill Assessment**
   - Take a 10-question quiz
   - Or skip to Act 0 if you're a complete beginner
   - Or manually choose your starting Act

3. **Character Creation**
   - Choose your name (or use default: Grixle)
   - Your progress is automatically saved

### Two Game Modes

#### Story Mode (Recommended)
- Full RPG experience with narrative
- Progress saved automatically
- XP and achievements
- Skip lessons you already know
- Manual save option in menu

#### Reference Mode
- Browse topics without affecting progress
- No save file required
- Perfect for quick lookups
- Review specific concepts

### Navigation

**During Lessons:**
- Follow prompts to learn
- Take challenges to practice
- (c)ontinue / (s)kip / (q)uiz options

**Main Menu:**
- 1 - Story Mode (your adventure)
- 2 - Reference Mode (quick lookup)
- 3 - Retake assessment
- 4 - View progress
- 5 - Settings (auto-save, hints)
- 6 - Credits
- 7 - Exit

### Tips for Success

✅ **DO:**
- Type the code yourself (don't copy/paste)
- Experiment with examples
- Use the skip system if you know topics
- Take breaks
- Save progress manually if you want

❌ **DON'T:**
- Skip challenges (that's where learning happens)
- Rush through lessons
- Worry about errors (they're learning opportunities)
- Give up on first try
