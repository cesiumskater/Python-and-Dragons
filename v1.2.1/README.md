## 🚀 Quick Start

### Requirements
- Python 3.8 or higher
- Windows, macOS, or Linux
- Terminal/Command Prompt access
- (Optional) Git for Act VIII

### Installation

1. **Download the game file**
   ```
   the_verdant_code_1.2.1.py
   ```

2. **Run the game**

   **Windows:**
   ```cmd
   python the_verdant_code_1.2.1.py
   ```

   **macOS/Linux:**
   ```bash
   python3 the_verdant_code_1.2.1.py
   ```

3. **Follow the setup wizard**
   - Takes a quick skill assessment
   - Recommends your starting Act
   - Creates your character
   - Begin learning!

## 🔧 Troubleshooting

### "python is not recognized" (Windows)
- Reinstall Python and check "Add Python to PATH"
- Or manually add Python to your PATH environment variable

### "command not found: python3" (Mac/Linux)
- Try `python` instead of `python3`
- Install Python 3 from python.org
- Use package manager: `brew install python3` (Mac)

### Can't find save file
- Save file is in the same directory as the game
- Named `game_progress_v1.2.1.json`
- Can be manually deleted to reset progress

### Unicode/encoding errors
- The game automatically handles Windows encoding
- If issues persist, use Windows Terminal instead of CMD
- Or use UTF-8 compatible terminal

### Game won't run
1. Verify Python 3.8+: `python --version`
2. Check file is not corrupted
3. Run from command line, not by double-clicking
4. Check error messages carefully
