## 📖 The Story

### Setting: The World of Fraylon
A fantasy realm where **magic IS code** - specifically Python. The world is written in the Language of Nature (Python), and druids can read and manipulate this code. The **Cult of the Dragon** seeks to corrupt the code and awaken the **Iron Wyrm**, a draconic intelligence that will rewrite reality.

### Your Character
You are **Grixle Mossroot** (or your custom name), a goblin druid who must master Python from first `print()` statement to advanced cybersecurity to save the world.

### Your Mentor
**Elder Willowbyte** - A wise treant whose bark is inscribed with Python documentation. He teaches you the Language of Nature.

### The Quest
Progress through 7 Acts, learning Python topics that grow from beginner fundamentals to expert-level cybersecurity. Confront the Iron Wyrm in the final battle, using your mastery of Python's philosophy (The Zen of Python) to save Fraylon.

## 🚀 How to Play

### Starting the Game
```bash
python the_verdant_code_enhanced.py
```

### First Time Setup
1. Game displays title screen
2. Character creation: Choose your name (or keep default "Grixle")
3. Prologue plays (The Whisper of Fraylon)
4. Main menu appears

### Main Menu Options
1. **Story Mode** - Play the RPG adventure (saves progress)
2. **Reference Mode** - Browse topics by category/act (no saves)
3. **View Progress** - See your story mode advancement
4. **Quick Topic Search** - Search by keyword
5. **Exit Game** - Exit with save prompt

### Story Mode Flow
- Select "Continue Story" to play next lesson
- Complete teaching section
- Answer challenge question
- Progress auto-saves on success
- XP awarded
- Advance to next lesson

### Reference Mode Flow
- Browse by Category (20 categories)
- Browse by Act (7 acts)
- Select any topic
- Learn without affecting story progress
- Exit anytime
