# The Verdant Code - Version 1.1.5

## Quick Start

```bash
python the_verdant_code_1.1.5.py
```

## What's New in v1.1.5

This version adds **two brand-new lessons** and **enhanced D&D storyline integration**:

### New Lessons

1. **RepresentingTextLesson** - Learn Unicode, UTF-8, ASCII, and character encoding
   - Topic ID: `representing_text`
   - Location: Act 1 (Fundamentals)
   - Teaches: `ord()`, `chr()`, `encode()`, `decode()`

2. **ListGamesLesson** - Interactive dungeon crawler mini-game
   - Topic ID: `list_games`
   - Location: Act 2 (Collections)
   - Features: Playable game demonstrating list operations

### Enhanced Story Mode

All 7 acts now feature:
- **The Lost Language of Nature** narrative framework
- Python as the ancient language that powers Fraylon
- Enhanced act transitions explaining WHY you learn each concept
- Deeper integration of D&D lore with Python concepts

## Features

- **153 Python topics** covered (up from 151)
- **Story Mode**: Linear narrative-driven learning with progress tracking
- **Reference Mode**: Browse any topic without saving progress
- **Interactive Challenges**: Code validation and hints
- **Save/Load System**: Auto-save after each lesson
- **Table of Contents**: Browse by category or act

## System Requirements

- Python 3.8 or higher
- UTF-8 console support (for emoji display)
- Windows, macOS, or Linux

## Usage

### Story Mode
Follow the narrative from Act 1 through Act 7, learning Python while saving Fraylon from the Iron Wyrm.

### Reference Mode
Access any of the 153 topics directly through the Table of Contents for quick reference.

## The Seven Acts

1. **The Ancient Glyphs** - Fundamentals (I/O, variables, types)
2. **The Tome of Collections** - Strings & data structures
3. **The Branching Paths** - Control flow & loops
4. **The Art of Incantations** - Functions
5. **The Scrolls and Grimoires** - Files, modules & exceptions
6. **The Living Constructs** - Object-oriented programming
7. **The Grand Algorithm** - Algorithms & performance
